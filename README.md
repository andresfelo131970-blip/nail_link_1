# NAIL_LINK

Software de gestión para spa de uñas desarrollado con:

- Java Servlet
- Maven
- Apache Tomcat 9
- HTML/CSS
- MySQL

## Requisitos

- Java 17
- Maven
- Tomcat 9

## Ejecutar proyecto

1. Clonar repositorio
2. Ejecutar en terminal de Visual Studio Code:
   
```bash
mvn clean package
```

4. Copiar `target/NAIL_LINK.war` a `Tomcat/webapps` en disco /c:
5. Iniciar Tomcat
6. Abrir:

http://localhost:8080/NAIL_LINK/login.html
